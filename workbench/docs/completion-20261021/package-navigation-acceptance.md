# 整包主导航与精确范围恢复验收

本批将整包核查接入独立工作面和项目概览，保留既有单稿评审的历史入口。这里只记录导航、范围保护和浏览器交互证据，不将页面可达解释为正式评审资格或全产品验收。

## 实际使用路径

新项目默认打开概览。主要下一步读取投标包目录，允许用户明确进入某个包的所列修订，或进入资料登记；旧正文的处理状态和下一步保留在“单稿评审历史与原流程”中。

桌面导航保留项目概览、项目资料、整包核查、章节编制、实交与成绩五个主要入口，其他工作区放在“更多工作区”。菜单保留真实链接，支持 Escape 关闭并恢复按钮焦点。宽度不超过 1000px 时，改用显示当前工作区的原生选择器，避免靠横向滚动寻找入口。两种导航都经过同一个范围保护，选择被阻止时仍显示原工作区。概览中的完整修订 UUID 和摘要可展开核对。

独立整包入口为 `/bids/{bid_id}/packages`。明确选择之后，URL 带 `package`、`revision` 和可选 `inventory`。刷新、浏览器返回与前进使用这些确切身份，不因目录头发生变化而改用最新修订。切换包修订时清除旧清单；选择新清单后更新完整范围。

包与清单的读取同时核对项目、包、修订、摘要和清单所属范围。未知参数、重复参数、不完整身份、错误路径及失效或越界目标会显示错误；只有用户明确回到目录后才重新选择，不静默回退到其他版本。

目录加载中、失败、结构异常和仍有下一页分别显示。只有已经成功读取且确认没有后续页的空目录才可以称为空；第一页没有条目但仍有后续页不等于项目没有包。读取目录不会保存、启动运行或调用模型。

## 范围切换和未确认命令

整包工作面使用局部 scope guard 汇总当前挂载控制器的真实状态。每个控制器有独立 token，卸载只撤销自己的回报，不清除其他控制器的忙碌、未确认请求或未保存输入。

- 包编辑、条款更正、覆盖范围、事实修改和依赖计划中的未发送改动会阻止普通导航及浏览器历史切换。明确放弃本地修改或收到经验证的保存回执后才解除。
- 冻结输入、执行输入、核查启动、人工决定、报告导出和取消等深层控制器回报真实 busy／pending；不是只在最外层表单设置锁。
- 已持久化的未知请求与尚未保存的表单分别提示。刷新后恢复沿用原 body、原幂等键和原 ETag；错误 ACK、错误范围或 `COMMAND_INCOMPLETE` 不解除恢复锁。
- 成功业务回执只在当前相同范围更新 URL。尚有其他未确认命令或脏稿时，新的条款更正结果保留在历史中，不强制切走原清单。

这里没有扫描或重新定义全局命令存储协议。历史控制器仍按各自原请求恢复；本批不改整包提交和官方成绩的命令语义。

## 浏览器证据与边界

[浏览器回执](package-navigation-browser-receipt.json) 保留各视口结果、场景、截图摘要和合成边界。仓库可直接查看 [桌面项目概览](screenshots/package-navigation-overview-1200.png) 和 [手机项目概览](screenshots/package-navigation-overview-390.png)。其余截图摘要也列在回执中。

包和清单来自实际非 owner PostgreSQL 服务的既有合成提交夹具，浏览器使用原样固定响应。登录、目录、当前规则和材料读取是为本次导航构造的网络边界；浏览器没有连接生产数据库，也没有下载或校验实际原件、运行模型。

三个视口均核对：精确选择、重新加载原范围、返回原范围、未发送改动拦截、切换清单拦截、错误 URL 零包读取、失败目录保持未知。取消脏稿后先等待实际范围锁解除再切换工作区。全程零写请求、零隐式读取当前头。

新版还核对桌面五个主要入口、更多菜单不被裁切、Escape 焦点恢复；768px 与 390px 不显示水平菜单，选择器保留正确当前值，所有视口导航无水平滚动。已人工查看新版桌面与手机概览、桌面展开菜单，以及精确清单和离开保护等既有场景；几何无溢出不代替目检。旧导航截图只保留为本地过程证据，仓库图片和回执对应最终导航。

## 仍需独立验收

本批不证明需求清单完整性、模型准确率、正式评分或标准提交资格。精确整包任务接线已有独立验收；目标部署和业务人员使用真实资料的验收分别记录，不因主导航贯通而自动完成。已有 [整包提交与官方结果验收](package-submission-outcome-acceptance.md) 的资格边界继续有效。
