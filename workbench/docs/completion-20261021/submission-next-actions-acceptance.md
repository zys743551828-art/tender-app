# 实交关联报告的同源动作验收

## 范围与边界

提交历史卡和“稿件与阶段”的实交原记录，在完整验证实交登记绑定后，读取其中明确关联的原核查及结果。复用[确切运行六级动作协议](../../packages/contracts/package-next-actions.md)和既有只读接口，不新增权限或后端结构。当前待核对内容与登记时冻结的四类检查分别展示；旧登记、历史风险及原报告均不改写。

未关联核查、或登记时未关联已完成报告，显示关联数量未知，不查询其他运行。固定包／修订／清单／运行／输入／结果不一致时拒绝；切换登记绑定丢弃晚到响应。编辑登记期间保留只读计数、禁用定位。规则和资料包沿用宿主导航；原报告打开使用保存的冻结输入、执行准备、计划、方法、操作及结果引用，并继续由既有详情加载器完整核验原生输入。

这是明确实交记录的关联核查待办，不是对整个项目的当前风险统计或新提交许可。登记表单中的未提交选择、无明确核查的项目目录及完整首屏视觉仍独立实施，F05-05保持进行中。
