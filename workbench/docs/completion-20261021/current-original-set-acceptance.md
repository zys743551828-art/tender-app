# 原生完整原件集合读取验收

[完整原件控制器](../../packages/contracts/package-current-original-set.md)先从独立当前scope端口取得准确冻结文件清单，逐份进行原生定位与受限完整GET，结束后重新读取scope并核对每份定位及全部来源。不接收调用方文件清单、按摘要合并身份或截断；超32份／每份32MiB／总64MiB在网络前拒绝。两条原生连接不跨网络持有事务。

字节及完整scope事实只在不参与repr的私有字段中提供给后续派生／投影；metadata只保留身份、长度、计数和两轮观察／读取回执。私有签名函数失败转安全码并丢弃异常上下文。没有新增数据库权限，复用用户已允许在全新独立检查库安装及清理的两能力组／两RPC；正常业务库不安装定位权限。

Linux **65项，26.94秒**：9集合原生PG、35读取、9导入隔离、12编排；Windows **44项，3.29秒**，与Linux重叠。四文件ruff／格式、两实现mypy／bandit通过。实际回环TCP按原生清单读取两份合成原件共122字节，即使内容摘要相同仍保留两个文档身份；两次网络时两条核验连接均实际idle。初末原生观察及全部字节回执记录在[脱敏证据](evidence/current-original-set/original-set-native-proof.json)。

首份GET期间撤回来源、末份GET期间项目关闭、首件字节损坏、过期scope／方法、总量超限、私有签名异常和读取取消均拒绝返回集合。取消后两条核验连接idle；没有返回部分集合或生成正式binding。最后核验仍是新的数据库快照，不保证此后不会再变化，发送前必须另有CAS／lease。

`native_scope_and_complete_original_set_observed=true`只表示完整集合读取流程通过，原生解析内容、必要范围、输入权威、执行和历史存在性仍false。真实OSS／S3读取、真实标书或付费模型调用0；未验证真实PDF质量及真实评分效果。所有既有方法及旧记录保持，6修改输入与11证据核Git，散列见[验收回执](evidence/current-original-set/receipt.json)。
