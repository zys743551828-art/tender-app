# 静态PDF原页与同像素裁片验收

## 已实现范围

独立[资产契约](../../packages/contracts/package-technical-page-assets.md)和处理器校验owned预期原件SHA／字节数与方法身份，保留全部PDFium物理页可见视口、内嵌旋转和实际派生时间。注释参与渲染，表单及孤立Widget在渲染前拒绝；不扁平化或改变原件。固定每PDFium画布单位3像素，不冒称已核物理DPI。超页数、像素、字节或软时限均失败，不返回截断候选。

细节来自明确原页像素矩形，不缩放、不替代整页；父回执、全部原页和全部裁片都保留。核验重建父摘要，逐像素比较裁片与父区域；修改裁片后重新自算外层摘要仍被拒绝。封闭RGB PNG编解码使用标准库，生产路径不依赖Pillow转换。文本解析与图像处理共用PDFium进程锁，原文本提取函数及解析／配置摘要表达式AST一致；原非数值特征方法摘要不变。

此实现无数据库、对象存储、provider或公开API端口。原件当前权限、完整必要范围、可读性、历史已存在和字体／色彩复现均未获得证明，资格标志始终false。进程锁与软时限不是安全隔离；生产不可信PDF必须先装配独立受限资产Worker，当前没有硬抢占或沙箱资格。PDF创建元数据不能证明原件在历史时点已取得。
