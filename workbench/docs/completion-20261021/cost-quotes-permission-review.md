# 原生完整材料费用报价权限审查

新material_cost_quote及tender_material_cost_quote仅在全新独立检查库可选安装，不进入BASE37、正常业务库、API／Worker／HTTP或前端。报价LOGIN与封存／核验／目标程序及请求者分别认证、固定OID，只继承报价purpose，只有quote／read，无表／列／序列、其他RPC或私有函数权限。

初始化者发布不可变政策，固定实际报价账号epoch、准确封存profile、origin、报价／SQL／费用／provider／serializer／judgment方法、完整价格策略及来源摘要、每槽尝试上限和数据库身份；head及修订单列。政策固定实际四SQL函数正文／owner／配置指纹；价格来源声明是批准配置，不冒实时账户合同或实际账单。

写入口独占RC／RW，只收固定封存／政策引用、command和币种／预算整数／尝试。治理→bid→图→command互斥后复核，政策、封存、独立核验、程序／审核及完整来源head行锁内核当前状态。跨purpose消费不能复用要求封存者session的身份布尔；须独立复核记录的封存者LOGIN／OID、purpose、profile／修订、DB／有效期、准确核验及完整字节存储。当前context由私有原生对象读取，不接受调用方规则子集、单价或正文。

价格字段闭合，USD／CNY无隐式汇率；金额、容量和尝试拒绝bool／浮点／字符串金额及负值。来源观察与有效期显式时区且最长24小时，输出容量覆盖固定4096、不得超上下文容量。全部纳入规则保留，每条三个有效槽、每槽1—5尝试且不超批准上限；先按完整上下文容量＋4096输出向上取整，再乘全部槽和尝试，numeric中间计算后限SAFE_INTEGER。预算不足返回完整所需金额及不足状态，不创建部分任务。

原生记录绑定真实UUID／时间／LOGIN／OID、完整封存、政策和原纯报价metadata。提交前独立重建算术及固定引用／方法，异常回滚。同command准确重放、预算或尝试变更冲突，四连接只一记录；新报价ID不构成新的模型调用意图，不能绕过后续任务／调用的语义去重。read独占RR／RO，只读本主体及OID，旧金额与本次政策／价格／材料有效性分开，过期不修改历史或复用旧as_of放行。
