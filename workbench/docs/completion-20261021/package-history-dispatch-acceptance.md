# 严格历史CPU派发与查询执行配置验收

本实现推进F06-07／08的已登记研究任务派发，以及F02／F13的本机运行机制。基础为已合并主线及44ebd9d。原始证据见[evidence/history-dispatch](evidence/history-dispatch)，协议与安装顺序见[派发契约](../../packages/contracts/package-history-dispatch.md)。不关闭正式图文评分、受控模型发布、真实配对精度或完整目标环境交付。

## 实际行为

- 独立train／evaluate进程只发现已经明确登记的同用途任务；目录返回编号、代次和精确时间，不返回研究正文、证明、标签或最终集。API、普通Worker和verifier不能发现，两个CPU用途不能混用。
- 新只读RPC核完整共同曝光守卫，限制每页1—20项并按稳定游标前进。queued及过期running可被发现；暂停、取消、终态和有效租约不列出。发现不领取，不授来源或执行资格。
- 原执行器继续核对当前来源、代次、owner／fence、租约和心跳。最终评估仍先提交曝光再另开连接读最终集。旧请求、已存结果和历史方法不改写。
- 陈旧／竞态任务保持deferred并向后扫描；空页回绕，下轮再核。连接／权限故障停止派发，不强制接管或补造结果。SIGTERM／SIGINT停止后续领取，当前owned执行依原协议收尾。
- launcher使用原0600单用途profile与固定隔离子进程。默认只跑一轮；明确选择多轮时才轮询，不创建开机任务、Codex后台接续或默认模型消费者。

`completed`是本轮核对到成功结果的数量，竞争时可能包含原结果重放，不代表新增CPU调用或发布次数；真实竞争验收确认同一job只有一份持久结果。

## 查询开销定位与修正

首轮和复现轮均为26通过／1个训练子进程超时，耗时207.91秒及206.88秒；子进程原120秒上限保持，原失败日志和XML保留。只读诊断显示数据库持续计算而非锁等待。

在同一有效租约、同一训练导出上分别显式开启／关闭JIT：最终冻结轮为**32.814秒／0.226秒**，内容摘要均为`d9deb969bf91e6fb09db5797022c2c1e8cef1a5aa5ddba4dc149069591fab040`。先前对照轮为32.149秒／0.218秒，也保持各轮内部摘要一致；不同轮使用新合成身份，不要求跨轮摘要相同。

预览、检查与完整Compose的PostgreSQL命令明确为`postgres -c jit=off`，完整配置结构校验拒绝覆盖。没有修改CPU数学方法、来源、资格、租约、角色或测试断言；该单查询证据不推算整体吞吐、端到端P95或生产容量。

活动配置与源码固定LF，证据目录使用Git的`-text`属性保留原始字节；归档时逐项核对测试输入、暂存源码与证据SHA。既有预览证据中被Git换行归一化的文件已按原始归档字节还原，22项摘要一致，不改写历史提交或测试结果。

SQL清单另存验收时原始SHA、Git字节SHA及实际执行文本SHA：两份既有SQL在旧Windows检出中为CRLF，Git中为LF；按测试器实际`read_text()`取得的执行文本一致。没有改写这两份旧契约，也不宣称它们的原始字节相同。新配置／新检出仍须按其实际字节重新冻结，不借本记录自动升级旧环境。

## 使用与交付边界

按原独立研究环境安装顺序，在完整共同曝光bridge之后额外安装`deploy/sql/package-history-dispatch.sql`；不得把它直接应用到未知业务数据库。BASE和默认v14不增加研究SQL，不启动本进程；既有恢复收据也不因此自动涵盖新扩展。

在有POSIX私有文件语义的明确Linux研究环境，分别启动两个用途，profile仍各只有对应一个DSN：

```sh
python -I deploy/package_history_dispatcher.py --purpose train --profile "$PRIVATE_TRAIN_PROFILE" --batch-size 5 --cycles 100 --poll-seconds 5
python -I deploy/package_history_dispatcher.py --purpose evaluate --profile "$PRIVATE_EVALUATE_PROFILE" --batch-size 5 --cycles 100 --poll-seconds 5
```

两个命令应由各自明确配置的进程运行，不共享profile或凭据。只跑一轮时省略cycles；进程内持有游标，短期单轮调用不承诺跨重启持久位置。完整研究部署装配、长期调度、目标Compose容器、正式模型与真实配对另行验收。当前本机API预览中的研究公开入口继续准确返回未装配503。
