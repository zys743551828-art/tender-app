# Desktop installation entry

The current installation guide is [the dev usage manual](https://github.com/zys743551828-art/tender-docs/blob/dev/使用说明.md). Use its recorded verification status and matching application revision. Application-side recipes are [build materials](../build-artifacts.md) and [Word execution and lifecycle](../word-execution.md).

The former instructions on this page described the full/1 acceptance environment, with operator-local test images and the broad development dependency set. They are retained in [the historical revision](https://github.com/zys743551828-art/tender-app/blob/35b9e3c6f84a43ac79a2f21b4a3616ae378f61d8/workbench/docs/completion-20261021/desktop-runtime-runbook.md), together with their original scope and evidence. Do not use those image names as clean-install prerequisites or treat that evidence as qualification of a newer full/2 installation.

Full/1 remains an explicitly supported compatibility contract; full/2 installs the separately versioned Word overlay. Root backend/frontend deployment is another historical application and uses different configuration.
