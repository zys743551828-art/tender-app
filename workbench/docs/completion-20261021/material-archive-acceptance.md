# 私有材料与页图持久化验收

完整 `/3` context 与全部整页／裁片可保存到私有 POSIX 内容仓库，并按调用方独立固定的清单及 context 摘要关闭重开、读取核对。原 PDF 不重复复制，全部来源、原解析身份及图像引用保留；同字节只去重内容对象。归档返回私有 `ArchivedMaterial`，不构造有资格输入或授予执行。

实现分工及闭合清单见[归档契约](../../packages/contracts/package-private-material-archive.md)：存储层负责受限路径、私有模式、目录锁、完整摘要与原子发布；归档层负责完整材料核验、对象集合与最后发布清单。无环境／数据库／云／模型副作用，无公开 HTTP、SQL 或权限变更。

最终验证为 **124 项 Linux 7.57 秒**：真实文件后端 29 项、归档 16 项、纯编码 14 项、原完整图文 35 项、端口隔离 18 项、Compose 12 项。**83 项 Windows 14.31 秒**覆盖纯编码、图文、三槽与隔离，套件有重叠，不相加；Windows 私有文件后端明确拒绝，未宣称 ACL 验收。八个 Python 文件格式／lint、两实现 Linux 目标 mypy／bandit 通过。

进程实际退出反例覆盖发布前不可引用临时对象、发布后按固定摘要恢复；并发 24 次独立实例写入只产生一个一致对象。短写、fsync 失败、锁等待上限、FIFO／软链接／硬链接、非属主／公开权限、损坏对象不覆盖、缺页、清单篡改、false→0、固定 context 串换、依赖读回失败及归档真正关闭重开均通过。合成两文档保留三份资产身份、去重为两份图像内容加一份 context，共三个对象；没有原 PDF 副本。

修复前崩溃测试为 1 失败／26 通过：硬链接发布与临时名删除之间退出会留下双链接，使完整对象不可读。实现使用私有目录锁内原子改名，最终包含该反例通过。[原始测试、源码摘要、边界及运行回执](evidence/material-archive/receipt.json)保留修复前和最终证据；中间通过轮次不累计。

十个修改输入核对工作树与 Git 索引原始字节，12 份证据固定 SHA-256。所有既有来源／范围／原件／解析／材料／渲染及 `/2`、`/3` 请求／判断／特征方法不变，旧记录不改写。

本机 5188 的 1212 份运行输入、68 份实际生产资源、登录／退出与服务边界核验通过，API／Web／PG 健康。正常库核验角色 0、design 136 表、BASE 37；独立库／LOGIN／核验能力组 0，checks／检查 PG／asset-renderer 停止，正常 Word 服务保留。研究可选扩展缺失仍返回明确 503。该环境为开发只读挂载启动观察，不是不可变部署。

业务写入、真实供应商调用及付费调用均为 0。没有原生登记、必要范围证明、输入资格或发送租约，Worker 自动恢复尚未装配。未验证断电持久性、生产租户根目录供应、总磁盘配额／回收、云对象写入、真实评分精度及浏览器视觉。后续从可恢复对象继续独立原生登记／必要范围、CAS／lease、token／价格／费用账本及正式 Worker。
