# 外部 Word → Rich 导入：剩余实现与验收边界

记录日期：2026-10-21。**本项尚未实现，不能计入 M1 已完成能力。**
本文记录当前源码中可复用的能力、缺口和后续验收案例；不是新增接口或协议已经落地的声明。

## 当前边界

当前已支持 Word 原件接收、原件保留及受控转换，以及手工 Rich 编写、精确构建与输出采用。
外部 DOCX 到可编辑章节的结构化导入尚未接通，接收成功、转 PDF 成功或已有表图编辑能力均不代表导入完成。
[融合计划 F07-03](https://github.com/zys743551828-art/tender-docs/blob/13bfcf194f997c68216179bec72ab657d517d734/00-项目管理/标书工作台融合实施计划.md)要求预览章节、段落、表格和图片映射，并明示不支持内容。
据此可以先定义明确的支持子集；这是分阶段实现建议，不能据此关闭尚未实现的表图映射等要求。
在该子集之外，表格、图片、修订和其他不支持内容必须可见并有明确处理结果，不能静默展平、删除或冒充完整保真。

## 尚缺的完整动线

1. **精确 DOCX → mapping。** 固定同项目原件版本、摘要和转换方法身份，明确章节、节点及图片资产的映射。
   保留可追溯的来源关系，并区分支持内容、转换损失和拒绝项；不能从预检段落串推断完整文档结构。
2. **mapping → candidate。** 形成可读取、可恢复的候选，绑定目标草稿/章节修订、转换结果摘要和损失清单。
   候选生成不能直接覆盖正在编辑的草稿；来源正文和内嵌资产仍须遵守既有私有存储边界。
3. **candidate → 结构预览确认。** 展示章节去向、替换范围、真实表格结构、图片及不支持项，允许明确取消或拒绝。
   不能只展示文本 diff 后宣称用户确认了合并单元格、图片身份、编号与修订的处理结果。
4. **确认 → CAS 应用回执。** 应用时重新核对来源及目标版本，以确定的幂等请求产生可恢复回执。
   来源撤回、项目关闭、目标修订变化和重复请求必须沿用对应守卫；丢失 ACK 不能导致重复导入或悄悄换请求。

以上是待补的行为要求；具体 DTO、持久化形状和路由尚未在本项实现。
已有内部 `prospective` 和单段 patch 可提供实现基础，但不能直接拼接成“已经具备完整导入协议”的结论。

## 支持子集必须说清楚

- 段落、标题、列表、强调、表格、图片分别声明支持范围，并展示无法保留的属性。
- 合并单元格、列宽、表头、图注及图片版本须按实际能力处理；不支持的结构明确拒绝或列出待确认损失。
- Word 修订须显式说明保留、拒绝或采用哪一状态；不能隐式接受修订后声称原稿完整导入。
- 域、外链、嵌入对象、页眉页脚及复杂样式等，不能在未支持时静默消失，也不能绕过原件接收与转换安全限制。
- 导入成功仅表示所声明子集写入成功；原件保留、编辑保真、PDF 对应关系及可提交性分别判断。

## 有意义的验收案例

以下是后续必须执行的验收案例，本记录不宣称它们已经通过。

| 案例                                   | 应观察的结果                                                             |
| -------------------------------------- | ------------------------------------------------------------------------ |
| 同一真实 DOCX 含段落、标题、列表和强调 | 支持内容映射稳定；来源版本、转换结果与目标节点可追溯，重复预览不改草稿   |
| 表格含合并单元格、不同列宽及单元格正文 | 显示实际映射或明确拒绝；预览、应用、再次编辑及构建均不静默丢失正文或结构 |
| DOCX 含内嵌图片和图注                  | 每张图绑定实际资产版本及来源；取消或失败不把不完整资产映射写入正文       |
| 修订、复杂域、外链或不支持对象         | 显示具体处理结果或阻断原因，未确认的损失不能自动应用                     |
| 导入到已有多章节草稿                   | 明确新增/替换/保留范围，未选章节和已有内容不会被隐式覆盖                 |
| 预览后草稿或章节被另一请求修改         | 应用遭遇 CAS 冲突并保留可理解的候选状态，不覆盖新内容                    |
| 预览后来源撤回、祖先失效或项目关闭     | 新应用被对应资格守卫阻止；历史记录不被改写成新的成功                     |
| 用户拒绝、取消或资产处理部分失败       | 草稿不发生半次导入；结果与可重试范围明确可见                             |
| 应用响应丢失、刷新后重试、重复点击     | 使用原 key/body 恢复同一回执，不能追加两次章节或混用另一候选             |
| 真实 DOCX 完成导入、再编辑、保存和构建 | 检查生成 DOCX 的结构及实际渲染；表图预览正确不能仅以纯文本断言代替       |
