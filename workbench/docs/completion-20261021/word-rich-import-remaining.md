# 外部 Word 导入：当前范围与剩余限制

2026-10-21 的后续检查点已经接通此前缺失的外部 DOCX → 可编辑 Rich 章节路径，详见 [实现与验收](word-rich-import-acceptance.md)。不再把 Word 接收预检的段落串作为导入结果；新的独立解析器、候选、预览、明确确认和原子追加均已落地。

已支持层级标题、段落、简单列表、粗斜体、原生合并表格及列宽、未变换的内嵌 PNG／JPEG。候选展示真实结构和图片，转换警告须逐项确认。原件保留；重复请求、草稿冲突、来源撤回及关闭项目有相应拒绝和历史恢复行为。

## 仍有明确边界

1. 不承诺任意 Word 完整往返保真。新稿使用工作台版式，页面、字体、段落格式、页眉页脚等不能保留的属性在候选中说明。
2. 未处理修订、动态域、复杂编号、脚注尾注或批注、外部关系、浮动／裁剪图形和未知对象仍明确阻断。用户须在原件中明确处理后重新导入，不能勾选忽略阻断项。
3. 本次只追加新章节，保留已有正文。自动覆盖已有章节、任意章节合并和复杂版式映射不在本次已支持路径中。
4. 默认 API 预览环境没有完整 Word 接收和对象存储配置时，显示未配置原因；能力缺失不通过填充样例或伪造成功消除。
5. 真实复杂标书、工程师逐项比对、生产转换隔离、分页质量和旧库升级仍需独立验收。合成样本与本机转换结果不能替代这些证据。

原缺口的历史说明保留在前一 Git 提交中；本页与专项验收反映后续实现，不改写此前阶段的测试结论。
