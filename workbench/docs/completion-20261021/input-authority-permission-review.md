# 独立输入核验权限审查

新权限只在全新独立检查库安装；BASE37、正常业务库、API／Worker、HTTP及前端不接入。独立LOGIN只继承tender_material_input_verify，允许qualify／read两入口，无表／列／序列或其他函数权限，与目标程序、命令请求者的实际LOGIN及OID分别配置、认证。拥有相同purpose的其他LOGIN也不能代签已分配政策。

初始化者发布不可变政策、方法／renderer镜像和源码、审核主体种类、DB身份、有效期与程序事实年龄上限；运行账号不能自配或更改。政策另固定实际安装的五个SQL函数正文、owner及配置的原生指纹。Python方法是批准接口指纹，不能据此声称数据库独立证明Python进程执行；认证程序完成是上一独立步骤的原生事实。

qualify持有自己的RC／RW事务，仅接固定原生完成ID／摘要、政策ID／摘要及command。治理→bid→图→命令互斥后重读，政策、程序／审核head及完整来源head按序行锁内复核；同command重放保留旧事实，不同内容冲突；同完成／政策／政策修订仅一事实，重开不依赖内存。结果闭合字段与引用校验发生提交前，异常回滚。

read独占RR／RO，只查本实际LOGIN及OID的固定记录；旧事实与本次时效／当前政策、程序、审核、方法及完整来源分别返回。撤销、替换、修订、账号重建、关闭／来源变化或过期不改旧回执，也不能复用其历史通过资格；只读观察不授发送lease或跨I/O原子快照。

运行时审查实际递归角色、表／列／序列权限、PUBLIC过授权、入口及三个私有函数正文／owner／UTC配置；私有函数运行账号无EXEC。报错仅固定协议，不输出PG原始细节、正文、定位符、连接串或密钥。临时账号／数据库／十四组及宿主端口／桥接清理，正常Word服务保留。

合成fixture可以证明software_input_verified和真实原生绑定；origin使input_verified／input_authority_granted／necessary_scope_verified继续false。执行、原始判断可发送、数值合计／正式预测、历史样本、实际人工阅读、历史存在、原子快照及lease均不因此授予。当前生产政策及真实精度另验，不将合成数据改标成生产正例。
