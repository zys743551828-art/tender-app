# 直接整包报告的同源下一步验收

## 交付范围

整包核查工作区的直接报告复用[确切运行六级动作](../../packages/contracts/package-next-actions.md)。绑定从已经通过原生验证的所选运行取得，包含项目、包、修订、清单、冻结输入、执行准备、依赖计划、方法、原运行及结果摘要；不构造工作上下文，不读取最新报告。请求仍为同一个只读接口，没有新增权限、表或后端协议。

主要动作定位本轮原报告，处理中的运行定位本轮状态；规则和资料包使用项目宿主提供的导航，沿用已有离开保护。没有同项目导航时不生成跳转。结果到达后按结果摘要重新读取动作；观察失败隐藏此前动作和数量，已经验证的不可变原报告保留。界面复用局部换行／最大宽度约束，Provider不增加DOM包装层。

直接报告校验要求ID属于所选原矩阵，分别核对历史关键问题及其他建议，拒绝在总数不变时将关键问题移入建议。处理中的运行不借其他报告补数量。资格仍为false，所选范围的计数不等于整包风险或提交许可。项目列表仍仅目录摘要；提交入口继续独立贯通，F05-05保持进行中。
