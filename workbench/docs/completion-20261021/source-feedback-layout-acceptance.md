# 来源侧栏、原页切换与状态反馈验收

日期：2026-10-21。范围：UI 39 点审阅中来源查看、主工作面保持、窄屏单任务、错误详情、首次加载及空态下一步。

## 已实现的行为

桌面在正文旁为查证／原件保留独立空间，正文仍可编辑；空间不足时切为单个模态任务。查证打开原页时保留父面板与原问题，暂时禁用其交互，关闭原页后恢复原触发按钮。关闭旧侧栏只释放它自身的空间预留，不会清除新面板的布局。

原件和解析文本共用物理页选择。窄屏和窄侧栏一次显示其中一份，切换不卸载 PDF canvas、不重置物理页；界面始终保留解析缺口与历史来源提示。解析响应及下载地址均核对明确文件版本，文件切换后的迟到响应不能覆盖新文件，错版本地址不会触发原件请求。

首次读取使用有标签的骨架占位；空态提供明确的重新读取或领域动作。错误主信息和重试可见，错误代码、请求标识与技术详情默认折叠。项目搜索无结果时可清除搜索。辅助小字由 10 px 调整为 12 px。项目列表旧单稿提示明确保留旧路径名称，本批尚未制造整包风险摘要。

## 实际验证

| 验证 | 结果与范围 |
| --- | --- |
| 定向组件测试 | 8 个文件、43 项通过；包括桌面正文可编辑、预留空间所有权、嵌套父面板、异步失焦恢复、原页／文本切换、迟到或错身份响应、共享反馈与既有工作面 |
| 实际 Chromium | 1440／1280／768／390 px × 浅／深色，共 8 组、24 张截图；0 页面错误、0 外部请求 |
| 实际 PDF | 内嵌生成的三页合成 PDF 经实际 PDF.js Worker 绘制；从引用物理页 3 打开，再切至物理页 2，canvas 与页选择保持 |
| 用户上下文 | 桌面查证期间继续改正文；关闭原件与查证后，正文和原问题保留，焦点回原触发按钮，滚动锁释放 |
| 类型与静态检查 | 整应用 TypeScript、所属 ESLint 通过；最终冻结候选全量构建与回归另见检查点汇总 |
| 视觉复核 | 已目检 390 px 深色原页与文本、1440 px 浅色原页；没有正文遮挡、横向溢出或双份原件挤在窄屏 |

浏览器使用一次性隔离 bundle，记录实际 24 个依赖文件的 SHA-256、bundle、PDF 字节与截图摘要。全部 API 数据为明确合成 HTTP；PDF 是真实可绘制文件。这不等于浏览器直连业务后端、私有原件或模型质量验收。

第一次浏览器执行发现测试选择器同时匹配父检索摘录和原件解析文本，已限定到原件面板。第二次发现实际浏览器会在异步来源核对禁用按钮时丢失原焦点；现于请求前固定触发按钮，在关闭后的 React 提交完成后恢复。保持原严格断言后，八组全部通过。延迟请求组件测试也覆盖了这一真实失焦过程。失败轮次未登记为通过。

## 与 39 点审阅的关系

[39 点审阅](ui-39-point-review.md) 是本批开始时的静态基线；本文件和[助手确认卡／来源详情](assistant-review-details-acceptance.md) 记录其后已完成的软件路径。仍需继续实现整包项目摘要、四阶段确切关联和其余分项，不能用本批截图或主题一致性宣布全部视觉目标完成。

本批没有修改正文保存、提案采纳、真实文件来源资格或正式评审门禁。通用原件入口的读取不能代替领域冻结输入校验，部分解析不会显示整包通过。

完整源文件摘要、浏览器流程、截图摘要与修正记录见 [检查回执](source-feedback-layout-checks.json)。
