- B4 固定真实草稿修订、快照与全部输入，生成实际 DOCX 并校验 S3 字节，再通过独立明确动作追加到投标包新修订。构建和入包前重新检查当前来源、事实与权限；混合快照中的旧章节保留原守卫，不自动核查或授予投递资格。
- 未知回执保留原键、原正文和原条件头。来源后来失效不改写原 ACK、快照和生成历史。仅撤回新写入所需权限、且原请求与历史读取依赖仍完整时，原结果仍可恢复；新用途继续执行当前检查。草稿只读不妨碍章节导航，已经发送的原请求仍可恢复。

当前固定采纳仅支持纯文字稳定节点。包含这类修订的草稿暂不开放普通编辑、旧版恢复、结构修改或 Word 导入；可重新捕获该快照并生成、采纳下一轮候选。真实第二轮已验证产生 r3。无冻结目录／版式的快照使用既有内置正文模板，避免 UI 误传双模板触发 `BUILD_TEMPLATE_SNAPSHOT_MISMATCH`。

## 检查点 16：严格整包历史研究操作界面（本地，尚未发布）

### 已接通的行为

- **项目内明确准入。** 在确切已保存技术范围下选择同一包修订的实交与官方成绩，读取严格准入依据，核对原时间、官方零分或未知值、来源与独立核验回执，再明确保存回溯准入。不要求手输业务 UUID，不默认选择最新记录；缺证明或正式条件时保留阻断。合成机制证明不能升级为真实证据或正式样本资格。
- **全局明确研究。** “评分研究”默认打开整包历史研究，既有单稿研究需另行打开。用户逐份读取准入详情、明确选用及指定用途，选择已冻结 CPU 协议或核对当前方法后另行冻结，再按明确的实交分界与标签截止冻结研究组。可填写北京时间，也可保留含时区的微秒精确时点；不能回填原实交或训练冻结时间。
- **任务与结果分别核对。** 在当前依据仍有效的冻结研究组上明确登记训练或独立最终评估；界面显示“等待独立执行”，不会自动派发或运行。当前任务使用实际条件头与代次暂停、恢复或取消；读取训练／评估结果不自动发起新任务。完整关联组排除、迟到标签未知、官方零分、全部分母、原量尺误差、配对基线与缺失区间分别显示。
- **来源、权限与原请求保持。** 目录元数据不授执行资格，选择后读取详情，新用途继续重新核验。原正文、原 `If-Match`、原幂等键先保存再发送；刷新、切换步骤或回执不明不更换请求。401／403、依赖不可用或无法确认的成功回包保留原意图。明确 412 拒绝后重新读取当前依据并确认新动作。当前 CPU 方法变化不再抢先阻断已保存协议 ACK 的重放；新冻结仍核对当前方法。
- **未发送输入与身份隔离。** 研究步骤切换保留表单，项目准入切换检查用途保留输入与待恢复入口；离开相应范围前保护未发送输入。成员／范围变更后旧异步回包不能进入新身份。来源后来失效不改写原准入、研究组、ACK 或结果；历史仍依赖相应读取权限及完整依赖，不能承诺任意撤权后仍可读取。
