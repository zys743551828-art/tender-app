# 目标核验程序认证消费权限审查

全新独立检查库可选安装程序完成事实表与tender_material_verification_program NOLOGIN组，仅program_context／record_program_result两个窄RPC。实际目标LOGIN与命令配置的原生OID一致，不能借请求者或业务账号消费任务；没有直接表／其他schema／CREATE权限。私有program_state函数SECURITY INVOKER且运行账号不可EXEC，正文／owner／语言／UTC／search_path与两个definer RPC均审计。

程序取任务RR／RO，完成RC／RW，5秒语句超时，提交前校验结果。配置及case head须匹配命令冻结修订，当前请求者OID与用途、独立审核身份及有效状态另核。完成时治理→bid→图锁、任务互斥及相关head行锁之后重新核授权／原生完整来源；120秒末次来源观察期限及5秒未来时钟容差，迟到源或授权变化拒绝，不在I/O期间持事务。

完成记录绑定实际目标LOGIN／OID、命令、程序／端口／控制器方法、政策、字节profile、准确context／报告／登记／审核及完整执行观察。合成来源只用development_s3，当前来源只用oss_hangzhou。记录认证程序声明，全部必要范围／binding／输入／执行等资格false，数据库身份与元数据一致不冒真实人工或数据库已独立重算内核。

每命令唯一完成事实，准确重放优先、不同观察冲突；未知结果从实际程序连接查回，不重新GET／渲染，不从JSON构造实时能力。运行时无权限修复或角色切换；独立正向输入资格仍须另走政策和原生封存。

只在独立临时库初始化与测试，正常业务库／BASE／公开HTTP／UI不变。结束清理临时库、LOGIN、十三组、宿主端口／bridge并停止检查／渲染，Word与预览保留。无供应商或付费模型调用。
