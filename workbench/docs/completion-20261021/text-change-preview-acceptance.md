# 文字变化预览与复盘账号清理

本增量对应 F12-11，使用现有保存、生成、原请求恢复与 CAS，不改正文或候选的应用语义。

## 可用行为

- 局部修改和多章 AI 候选均可核对具体文字增删。未改文字保持原样；删除／替换同时使用颜色与删除线，新增使用颜色与下划线。
- 桌面并排呈现原文和拟稿；390px 单独呈现一侧，并可用键盘切换。完整文字保留在各自一侧；长文可滚动，不截取开头充作全文。
- 比较采用有界计算：共同比较前后段先保留，中间区域超过 250,000 个比较格时明确改用区块标记。超长替换仍保留两侧所有字符。
- 多章候选的文字差异按需展开，完整富内容前后稿继续独立呈现表格、图片和未改节点；文字差异不声称能够代表图片或表格结构变化。
- “查看差异”和“应用候选”分别操作；既有完整性检查、修订冲突、到期、失 ACK 和原键恢复继续生效。
- 整包复盘入口按需加载，收起后保留已挂载草稿。知识候选跳转复用全局导航保护。复盘草稿、选择、流转说明及原命令恢复记录参与退出／切换成员清理，保留当前同一成员的记录。

## 本轮实际证据

| 层次 | 结果 |
| --- | --- |
| 有界差异算法 | 9 项通过：空侧、同文、换行、组合字符／emoji、重复文字、120,000 字替换及完整重建 |
| 差异组件 | 1 项通过：全文、明确移动端侧别、输入更新；预览本身没有应用操作 |
| 复盘清理 | 1 项通过：两个账号各 5 类记录，切换仅清理离开账号，退出清除全部这些记录，其他存储保持 |
| 相关界面回归 | 与多章候选、实交、技术范围合计 6 个文件 34 项通过 |
| 共享契约与部署回归 | 实际 OpenAPI、包／结果契约、初始化、预览编排和恢复计划合计 64 项通过 |
| 浏览器 | 实际 Chromium，1280／768／390px、浅／深色共 18 个页面组合；其中 6 个组合验证真实差异组件，390px 验证键盘切换。无脚本异常、页面横向溢出或越界控件；9 组语义颜色对比度均至少 4.5 |

浏览器使用合成页面，原文／拟稿是明确合成文本；没有调用 API、业务数据库或模型。图像字体显示依赖浏览器字体，不把 DOM 字符保留等同于所有 Unicode 字形视觉验收。截图由测试脚本可重复生成，根已目检桌面浅色和手机深色。

最初新测试将 JSX 属性中的字面量 `\n` 误当换行；已修为实际换行并复跑全部相关 34 项。预览 v14 卷名在首次共享检查中被发现写入错误段落，已移回 `volumes`，保留旧卷声明；64 项全部复跑通过。旧未审研究 SQL 已移出默认恢复计划，并通过禁止重新纳入回归。

最终整应用门槛与源码绑定记录见本检查点汇总；这些局部结果不代表全 F12 或真实业务效果验收。
