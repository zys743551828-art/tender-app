# 外部 Word 到可编辑章节：实现与验收

记录日期：2026-10-21。本检查点继续实现融合计划 F07-03：接通精确原件选择、结构化解析、完整候选预览、限制确认、原子追加及历史恢复。支持范围由实际能力接口及每份候选的转换问题决定，原始 DOCX 继续保留。

## 用户路径

在「章节编写与生成」打开 Word 导入，选择同项目已接收并核验的原件，填写导入原因。界面先保存本地编辑、读取草稿修订，再申请导入候选；申请候选不会修改原有章节。

候选展示原件身份、新增章节层级、段落和列表、实际合并表格、经字节摘要核验的内嵌图片，以及原件到章节／节点的映射。用户须逐项确认转换限制，填写处理原因后明确追加，也可以拒绝候选。追加只新增根章节及其子章节，已有章节的正文、身份和修订不变。

刷新或丢失回执时，界面保留原项目、成员、草稿、请求体、条件头和幂等键，用原请求恢复；不会自动换键再导入一份。目标草稿变化、原件及其祖先撤回、项目关闭或图片字节变化会阻止新的追加。历史候选和已形成的回执仍可读取。

## 格式范围

| 内容 | 实际处理 |
| --- | --- |
| 一级至六级标题 | 转成章节层级和标题，正文不重复插入同一个标题 |
| 段落、换行、粗体、斜体 | 解析为现有 Rich 节点，保留文字与支持的强调；样式继承按实际定义解析 |
| 简单十进制和项目符号列表 | 支持从 1 开始、最多五层；复杂编号、无法核对的起始值明确阻断 |
| 原生表格 | 保留列网格和列宽、横向及纵向合并、表头、表题、全部支持的单元格正文；越界和不能映射的结构阻断 |
| 内嵌 PNG／JPEG | 保留原始图片及规范化 PNG，绑定真实资产修订；支持未变换的行内图片 |
| 页面、段落及字体版式等差异 | 候选逐项列出警告，新稿按工作台版式生成；原件保留 |
| 修订、动态域、外链、复杂对象、浮动或裁剪图片、未映射内容 | 明确阻断，不能通过勾选警告确认绕过；不执行域、不访问外链、不隐式接受修订 |

导入器复用 Word 接收的容器和 XML 安全检查。原件上限 32 MiB，候选上限 16 MiB，最多 500 个章节、200 张图片；另有节点、解压、图片总量及像素限额。加入现有草稿后的章节容量也在存储图片前检查，超限返回明确原因，不截断尾部内容。

## 一致性与来源

- 解析方法身份绑定解析器及全部辅助模块、Rich／文字 schema、原件预检与图片规范化源码，以及 Python、Expat、zlib、Pillow 和 codec 版本。运行中源码变化要求重启 API，旧进程不能把加载前的代码冒充新方法。
- 下载原件、解析 OOXML、规范化与读写图片都在数据库连接关闭后进行。最终事务重新认证成员，核对原件、草稿修订、事实和格式依据，再保存不可变候选。
- 确认时先在事务外核对所有图片，然后在同一事务中登记图片资产、追加全部章节、冻结快照并记录处理回执。任何一步失败都不留下部分正文或部分资产登记。
- 候选与处理记录只追加。SQL 独立检查同项目原件、已核验上传、请求及条件头、命令回执、全部警告确认、快照身份，以及原有章节未被覆盖；Worker 没有候选表的读写权限。
- 章节来源证明冻结到核心草稿快照。复制章节保留来源关系；删除所有相关章节后无关章节可继续使用，恢复章节时再次检查来源。图片资产另保存原件来源，复制到其他章节仍受约束。
- 生成、Worker 发布、生成物采用、新用途资格及 AI 章节上下文共用当前来源检查。生成 Word 的来源边包含导入原件，生成 PDF 再关联精确 Word，不能通过重新生成去掉原件的效力约束。
- 正常从已接收原件到文件采用不改变同一个原件的固定来源身份。实际重定向绑定、来源修订、撤回和自然到期仍需重新核对。
- 历史目录按创建时间和 ID 倒序，只读取摘要、计数及处理状态；详情才读取完整映射和正文，避免列表一次载入数百 MiB 候选。

同时修复旧建议接口的 Rich 格式标识：建议记录现在按实际章节内容选择 schema，含表图的章节可以应用文本建议，表格和图片继续保留。
