# 独立当前来源与确切解析观察验收

正式三评的[当前来源观察端口](../../packages/contracts/package-current-sources.md)使用独立非属主LOGIN，只有八张原件／解析／来源表的只读权限；原件表只开放八个元数据列，不开放对象locator。它从原生数据库重建完整解析证据身份、原件及解析UUIDv5来源和全部祖先，核对当前用途、发布、时间、项目及直接派生关系。全部读取位于owned repeatable-read／read-only事务，有显式容量及每条SQL超时；不读取历史核验器、官方成绩、实交、RAG、聊天或模型调用。

权限核验检查实际继承和PUBLIC效果，额外表／元数据列读取、写权限、schema／database CREATE及可执行SECURITY DEFINER都拒绝。API／owner／借用事务拒绝，方法与owned预期摘要错配或执行中改变也拒绝。可选SQL只在全新独立检查库初始化，未加入BASE、未给正常API角色补权，没有业务数据库安装。

最终Compose套件53项通过（3.87秒）：37原生PG、4隔离导入／实际API错误兼容、12配置；Windows4项导入／兼容1.89秒通过，范围重叠。四文件Ruff／format、两实现mypy／Bandit通过。实际独立LOGIN不能读取locator、实交、官方成绩、chunks或模型调用，额外授权被检测；撤回、未来、过期、标签混入、跨项目、摘要／parse错配和缺派生边拒绝。全部祖先均检查，节点／边／层级超限不返回截断结果，初始化owner在合成检查库暂绕写入守卫建立的循环也被观察器拒绝，守卫随即恢复。多余官方分字段、布尔冒整数、重复文档、非规范身份和超容量在数据库访问前拒绝。

并发来源撤回测试实际确认同次事务保持原快照，下一次观察立即拒绝。旧观察记录保持原字节含义，这份观察不等于发送资格或持续租约。只有原生解析及读取时来源状态标志为true；原件字节、必要范围、输入权威、执行和历史存在性仍false，结果类型不能充当正式核验binding。原输入／图文序列化／判断／特征及受限派生方法均保持，旧manifest、报告和回执不改。
