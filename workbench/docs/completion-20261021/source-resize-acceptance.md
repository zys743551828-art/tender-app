# 来源侧栏共享宽度与键盘缩放

日期：2026-10-21。基线：检查点 12 `ebe7e80`。本切片补齐 F12-09 的来源面板宽度调节，不改变来源或正文业务资格。

助手与来源面板现在使用同一个拖动／键盘边界组件。桌面可以拖动边界、用左右方向键逐次调整 24 px，或用 Home／End 到达本屏允许的最小／最大宽度。正文至少保留 620 px；空间不足时仍切换为窄屏单任务。

从查证或助手打开嵌套原件后，原件共享父侧栏的宽度与调整函数。父面板及其旧拖动边界暂时不可交互，只有当前来源边界参与键盘导航；关闭原件回到原问题或助手时保留刚调整的宽度。来源宽度作为浏览器布局偏好保存，重新打开可恢复；不形成业务选择或采用。
