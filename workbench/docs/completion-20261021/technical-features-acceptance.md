# 三次判断非数值CPU特征闭包验收

## 范围

新增独立[投影协议与边界](../../packages/contracts/package-technical-features.md)、封闭输入／输出Schema和纯CPU处理器，不改/1机制通道，不增加正式API、表、权限或Worker接线。owned控制器必须独立提供已冻结投影及当前特征方法摘要，收到的任意JSON自算摘要不授予输入或执行资格。

每条规则三个有效槽位，槽位与尝试分开；调用／供应商响应不可复用，语义输入／请求／方法／profile绑定固定值，成功或未知回执后不补发同槽。引用逐项绑定文档、解析、原文、物理页和页图，同页各块的页图摘要及尺寸不能冲突，区域不能逃出页边界。缺有效槽位时保留已评行、缺失／未知槽位与尝试计数，特征null，不补0、不插值。

三个有效槽位的规则输出档位票数、并列众数、分歧及具体性／有效性／一致性的三状态计数；没有档位映射仍保留维度特征。票数不是置信区间，图表数量不是加分特征。数值合计／正式预测始终null，输入权威、原字节、可读性、正式预测／训练／指标均不由特征函数授予。原响应／费用／实际调用真实性与完整图文输入仍由后续独立权威负责，不能用纯投影替代。

- 最终固定Compose **106项通过，0.87秒，0跳过**：54项新投影测试、42项既有评分契约／用途隔离、10项Compose检查。Windows当前54项通过0.88秒，属于Linux子集，不相加。原Python格式／类型修复及新增同页反例后对最终源码重跑；较早92／102及50项结果保留为阶段日志，不代替最终回执。
