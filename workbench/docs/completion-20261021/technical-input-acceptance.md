# 完整图文材料绑定验收

## 范围

独立[输入契约](../../packages/contracts/package-technical-input.md)与纯处理器将owned冻结投影绑定全部文档、解析、原页、裁片、章节、原文与规则来源。招标依据和本方材料分开，规则引文必须来自依据文档，必需范围根节点来自本方材料；父树无环，子页段包含在父范围内，跨节引用传递展开且有界终止。

每条规则都绑定全部材料摘要，全部冻结页图、裁片和证据保留，不按范围映射删上下文。全材料摘要只算一次，各规则的语义摘要绑定它、原投影、当前方法及完整规则／范围。原文或非根节点页的上下文变化也会改变语义输入。供应商发送时仍须实际展开完整材料，不能只发送摘要。

当前函数只核对外部owned投影的一致性；必要范围的语义完整性、原件真实权限和当前效力、解析正确性、视觉可读性均须独立权威核验。此处不重读原PDF、不装配公开API／SQL／Worker／provider，不授输入、执行、历史、正式预测或训练资格。闭包拒绝标签等额外字段，不能据Schema保证原文没有夹带信息，后续适配器必须有独立用途及最小读取权限。
