# 当前包与冻结范围的独立原生事实验收

[当前范围事实端口](../../packages/contracts/package-current-scope.md)使用独立非属主LOGIN，只能调用一个已核对正文、语言、返回类型、执行模式、search_path及owner分离的窄RPC。该LOGIN不能直接读任何业务表，实际读取范围表、审计、实交、官方成绩及RAG均拒绝；PUBLIC／继承的表列读取、额外角色和额外SECURITY DEFINER入口也被端口拒绝。被替换的RPC正文在执行前拒绝。

原生RPC核对scope准确摘要、当前项目阶段／提交存在性、已确认工程／标段／轮次／主体身份、目标包head、依据包head、要求清单head和当前规则集。逐项及组合限8MiB，调用方不能提供“当前有效”的JSON状态。完整旧scope、包与清单按原值返回，人工排除项、部分覆盖和必要范围unproven保留。原登记时字节核验回执不升级为本次对象字节核验。

最终Linux Compose37项通过（43.14秒），其中20项原生PG／真实API，5项隔离导入与错误兼容、12项编排；Windows5项2.14秒通过，范围重叠。四文件Ruff／format、两实现mypy／Bandit通过。实际API追加目标包、依据包和清单后，旧范围分别拒绝，旧回执保持；项目提交／关闭／终止、当前身份或规则集变化、错误scope／项目／摘要／方法及借用事务也拒绝。直接调用RPC但没有owned只读事务，数据库自身拒绝，不依赖Python入口。

只有`native_current_facts_checked=true`；必要范围、当前原件字节、输入权威、执行和历史存在性均false，不产生正式核验binding。独立当前来源图观察、原件字节、必要范围权威和原生回执登记仍需组合，之后发送前重核CAS／lease。既有原页、来源观察、输入、图文序列化／判断与特征方法均保持，旧报告不回填。
