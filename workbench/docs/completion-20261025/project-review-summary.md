# 阶段：项目概览中的所选核查与下一步

## 使用路径

项目概览新增“核查风险与下一步”。用户明确打开核查目录并选择一轮整包核查后，页面核对该记录的项目、投标包版本、清单、输入、结果、方法和选择摘要，再展示这一轮的六级下一步与剩余问题。按钮可返回同一轮原核查及报告，或进入该记录对应的投标包、规则核对入口。

初次打开概览不请求核查目录，不自动选择最新运行，不把投标包数量或某个旧报告当成当前项目风险。预测分数仍明确未评估。成员或项目变化、取消选择、上下文校验失败、快照刷新失败时会清除或隐藏旧选择对应的可操作结果；晚到响应不能恢复已取消的选择。

新增 `ProjectSelectedReviewSummary` 复用既有 `WorkContextChoices`、完整上下文校验和 `PackageNextActions`，未创建第二套风险排序算法或服务端写入口。交互只发 GET。独立 CSS 处理嵌套摘要、长文字、手机换行及主题继承；通过懒加载进入项目概览。

可复现命令（从 `apps/web` 运行，Playwright 单独安装，不改变应用依赖）：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright \
PLAYWRIGHT_BROWSERS_PATH=/path/to/installed-browsers \
node scripts/check-project-review-summary-browser.mjs /tmp/tender-project-review-summary
```

本轮使用 Playwright 1.51.1 / Chromium 134.0.6998.35；当前环境预装工具所指向的浏览器下载失败后，采用上述隔离工具完成实际检查。输出的 `result.json` 与截图是可重新生成的验收产物，CI 会保存为运行 artifact。
