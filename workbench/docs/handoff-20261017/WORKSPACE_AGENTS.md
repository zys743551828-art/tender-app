# 项目约束

- 当前目标是全新建设 AI 投标工作台。用户明确没有旧系统迁移需求；不设计旧库状态映射、旧代码兼容、双系统切换或旧模型资格承接。
- 历史标书、官方成绩等作为新系统的新资料入库；档案导出、备份恢复以及未来数据库结构升级仍需设计，不把这些称作旧系统迁移。
- 用户已指定消息基础设施使用 Kafka。目标方案按 Kafka 消费协议设计任务执行，不将 RabbitMQ 或 Celery 队列配置当作当前基线。
- RAG是目标能力。架构必须明确解析、分块、Embedding、向量与词法检索、重排、证据引用和来源失效处理。向量存储的具体选型见当前技术主记录。
- 正式评分仍遵守干净输入、完整相关章节和三次判断，不以普通聊天RAG片段替代完整评分范围。
- 当前主记录位于 tender-docs：产品行为见工作台PRD，架构见全新系统技术方案，实施协议见详细技术设计。历史调研和审查记录是当时证据，不能改成当前方案已验证。
