# 融合视觉令牌与语义映射

## 来源与适用范围

颜色来源固定为应用供体`45a5921011fa22f400482f73710e96a32b916082`的`frontend/src/styles/index.css`。融合工作台使用`apps/web/src/styles.css`中的一套普通CSS变量，不引入供体的Tailwind工具链或另一套组件。32个基础令牌的值与固定供体相同。

品牌继续使用“AI投标工作台／投标工作台”，品牌副标为“整份标书 · AI 辅助”，登录页脚为“AI 投标标书工作台”，登录说明及页面描述明确对象为投标标书。市政工程是当前业务验证类型，施工组织设计是技术内容，二者不限制总品牌；本批没有增加新logo、导航、业务能力或流程。

## 语义与兼容

| 语义 | 目标令牌 | 采用位置 |
| --- | --- | --- |
| 中性底色、正文 | `--background`、`--foreground`、`--card`、`--subtle` | 全局、登录、卡片及顶栏 |
| 次级表面、次级文字 | `--surface-muted`、`--muted-foreground` | 次按钮hover、默认徽标、次级说明及输入提示 |
| 边框、输入与焦点 | `--border`、`--border-strong`、`--input`、`--ring` | 共用边框、输入框和可见焦点 |
| 品牌及主要动作 | `--primary`、`--primary-hover`、`--primary-foreground`、`--primary-soft*` | 主按钮、链接、标志及相应柔和底色 |
| 危险／失败 | `--danger*` | 原有danger徽标与error通知，不改业务严重性 |
| 待核／提醒 | `--warning*` | 原有warning徽标及通知，不将未知换成成功 |
| 成功／已核验 | `--success*` | 原有success徽标；是否成功仍取业务事实 |
| AI身份 | `--ai*` | 助手回复标记及消息标题；AI身份不是核验通过状态 |

保留工作台已有变量名作为兼容别名，减少无关模块改动：

| 既有变量 | 目标含义 |
| --- | --- |
| `--green` | `--primary`，深绿主要动作 |
| `--green-dark` | `--primary-hover` |
| `--muted` | `--muted-foreground`，始终是文字色 |
| `--line` | `--border` |
| `--soft` | `--primary-soft` |

供体的`--muted`表示浅色背景，原工作台同名变量表示次级文字，两者不能直接覆盖。供体的背景语义用`--surface-muted`接入；正文不会因变量同名变成浅灰。HTML的`theme-color`必须与`--primary`同为`#0d5c55`，因为meta不能引用CSS变量。

这次只调整基础表面、已有共用状态和助手身份标记，未批量替换所有十六进制颜色。图纸／PDF高亮、差异和其余业务专用色继续保留其含义，后续组件逐项接入时核验。表格、弹层、编辑器及对话布局不重排；既有状态枚举与文案判断不变。

## 静态对比度与浏览器验收

采用sRGB相对亮度计算15组文字前景／背景和2组焦点／背景：文字均不低于4.5:1，最低为success前景对success柔和背景的5.396:1；焦点分别为7.838:1、7.510:1。次级文字对卡片5.953:1、对中性柔和底5.416:1，主按钮文字7.838:1，AI前景对AI柔和底7.848:1。原始计算记录在本机忽略证据`workbench/.local/f12-01-token-contrast.json`。

计算只验证指定令牌配对，不能代替实际继承、透明叠层、禁用态或完整WCAG验收。浏览器需独立核对：

1. 当前融合工作树的登录页，1440px及390px视口下的品牌、主按钮、placeholder、次级说明及键盘焦点；不能拿原8080供体页面截图代替。
2. 徽标／通知中危险、待核、成功及默认状态的实际前景和背景，AI消息明确采用独立靛蓝。样例展示只能证明组件外观，不冒充真实项目检查结果。
3. 计算样式中的`--muted`解析到文字色，边框与背景没有因兼容别名串色；改动未引入整页横向溢出或遮住操作。

登录表单容器使用`minmax(0, 1fr)`单列轨道，容器和表单均允许`min-width: 0`，表单保留`max-width: 100%`。手机宽度下表单须按面板实际内容宽度收缩，左右边距与焦点环空间均需实测；没有整页横向滚动条不能证明面板内部没有挤出。

静态质量已运行：修改的CSS／App／组件／HTML通过Prettier；完整前端lint、typecheck、37文件148项测试及生产build通过，品牌副标和页脚调整后另跑App四项回归。浏览器截图和实际计算样式由独立验收记录承接，静态结果不替代该验收。
