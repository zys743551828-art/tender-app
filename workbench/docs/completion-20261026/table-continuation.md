## 实现范围

表格检查协议升级为 `authoring-PDF-table-correspondence/2`，RICH 受控配置 `/5`→`/6`，图表混排和图注检查同步升级 `/2`。冻结 DOCX 源协议、外部 Word03 和 PAGE lane 不改写；旧 RICH 配置必须重新资格核验。配置摘要包含续表策略源码摘要和限制。

新增独立策略 `rich_table_continuations.py`：

- 仅连续两张物理页、同尺寸、同横向列位置，原表 2–12 行；所有单元格无跨行／跨列合并，每行文字签名可区分。
- 穷举受限切分点，每个片段从冻结的连续原行区间重建；沿用实际完整网格、精确单元格文字、数字和逐像素可见性核对。保留原 cell ID、原行号和物理页，不把两段记成两张独立表。
- 首片段是该页正文末尾，续片段是下页正文开头；两端距正文边缘最多 72 pt。空白区同时核查原生文字及可见栅格，防止脱离边框的重复表头、插图或其他正文被忽略。完整边界防止从较大网格截取子集来掩盖多行／漏行。
- 一个表只接受唯一的两个片段，不接受跳页、重复片段、列偏移、缺行、乱序、隐藏／遮挡。候选、工作量及栅格预算仍封闭，新增扫描和空白区像素工作也计入预算。
- 混排和章节归属逐片段核对；任何片段越过下一章边界，或别的图表插入该表片段顺序中，整体保持 partial。图注必须位于最后片段之后，其实际目的地、文字和可见性仍要核对。

**重复表头不开放。** 当前冻结源没有独立重复表头声明，因此附着或脱离网格的重复表头均拒绝；不能把“表头样式”自动解释为可重复。三页以上、超过 12 行、合并单元格跨页、不可区分的重复行及复杂布局仍保持 partial。单页表格的原有合并格支持保留。
