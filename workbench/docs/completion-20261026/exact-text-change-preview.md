# 固定来源文字修订：提交前逐节点差异对照

状态：实现、本地总门及最终真实浏览器复核已完成；提交后仍须核验精确提交 CI。

## 需求与范围

对应 FR-037 的文字变化标记、逐项核对、并发冲突差异及已保存／待提交身份区分。本项仅为已有 B5 单文字叶、B6 原子多节点、B7 保留原有 bold／italic 的人工文字修订补齐交互，不扩大可编辑对象或格式保真范围，不启用 AI 调用，也不代表 FR-037 整体验收。

开始修订并改字后，「本次文字修改对照」逐节点列出编辑基准与拟稿，原文和新文均保留全文。展开节点才计算既有有界差异；变化过多时说明按整段对照，不静默截断。桌面并排、窄屏切换前后，支持键盘展开。HTML 作为字面文字显示，Unicode 不被重写。

预览不是保存或内容认证，不改变人工确认、不自动提交或重试。未知回执仍按原 body／操作键／ETag 恢复，标签注明原请求；412 标注被拒绝请求并保留人工文字，只有显式重新核对后才使用新验证基准，不自动合并。若重新核对后原节点已不存在，仍展示该节点未核对的拟稿全文，不伪造空白原文或将其移到别的节点，保存保持禁用。批量仍保持最多 20 节点、合计 20,000 字符与全部成功或全部不改的原约束。

后端、SQL、OpenAPI、B5/B6/B7 协议、原生夹具和策略源码不改。真实复杂 DOCX 往返与业务人工核对仍是独立验收项。
