## 独立审查关闭的问题

- 提交前复核客户端原先可能接受“重新签名后删除原预览身份阻断”的回执。现在保留所有未由本次复核真正消除的原因，并拒绝把 blocked 降级；反例复验通过。
- 恢复隔离原先没有审计快照名单之外的新 reader。现在在建库前和隔离事务内检查实际读账号的全局权限、角色关系和 owner 能力，拒绝持有 `pg_write_all_data` 等权限的账号，保持源 membership 不变。
- 将对象复制到同桶新前缀无法让现有应用读取恢复副本。现在恢复到独立目标桶并保留不可变原 key，从恢复库读 key 后实际调用 `domain.storage.get`，逐次确认 GET 命中目标桶。
- 文字修订浏览器脚本原先把恢复按钮出现当作请求已经完成。现在等待实际请求和发送结束，再做严格次数及原请求断言；失败运行记录保留。
