- 最终侧：无标签 `/3` 原生输入、逐成员预测冻结、原生曝光绑定、曝光后独立评价和结果持久化、闭合 API/UI。见[最终评价阶段记录](feature-final-evaluation.md)。原生 SQL 没有执行，不能称为真实数据库联合验收。
