# 显式声明的重复表头

## 范围与版本

从独立分支已推送的 `6dc85ab` 开始；只读核对远端独立分支和 fusion 目标（`462ec226`），没有覆盖并行提交。

表格新增可选属性 `pagination: {protocol: "authoring-table-pagination/1", repeat_header_rows: 1}`。没有声明仍不允许跨页重复表头，`header` 样式不授予重复资格。严格拒绝未知键、布尔行数、空声明、不支持版本或多行表头。

RICH 内容 schema v3 保留 v2 的原摘要和严格读取路径；旧 v2 请求不能夹带新声明。编辑器接受服务端公布的旧摘要，新保存产生当前格式修订，不改写历史快照。实际 OpenAPI 和生成的 TypeScript 类型同步；插表面板增加默认不勾选的重复表头选项。合并操作不能把已声明表格变成不支持结构。

源生成协议 `/4` → `/5`，RICH 受控配置 `/6` → `/7`，表格对应协议 `/2` → `/3`。固定 Word03 和 PAGE 检查器不变；配置绑定新增正文展开代码与表格策略摘要，旧 RICH profile 必须重新资格核验。

## 生成、准入、验证

- 仅 2–12 行非合并表格，首行全部是表头单元格且只含段落；正文其余行仍按既有严格结构验证。DOCX 原生首行输出唯一 `trPr/tblHeader val=1`。准入拒绝后续行、未知属性、重复标记及错误父节点；精确源重组拒绝没有冻结声明的伪造标记。
- 一页表无需物理重复。跨页仅支持连续两页，首片段至少一行表头和一行正文，第二片段必须包含唯一、完整、可见的同一源表头和精确连续原行；保留实际页码、边界、原单元格 ID 与行号。逻辑 cells 不重复计数，物理 fragments 明确标记 repeated_header。
- 继续沿用完整几何、单元格文字／数字、独立栅格、页边空白、唯一片段和工作量预算。首片段只剩表头仍拒绝，不把第二页完整表误判为合法续表。
- 只有实际表格对应证明 complete 时，RICH 正文检查才在独立复制的 OOXML 观察模型中按验证到的切分点插入原表头，用原有完整正文检查器比较 PDF。绝不从 PDF 全文删除任意相同字符串，原始冻结源字节／树不变；同时记录冻结正文摘要和展开后预期摘要。导航、图注、图表顺序、跨节、字体等其他缺口原样保留。

外部 Word 导入仍显式报告 `TABLE_HEADER_REPEAT_NOT_IMPORTED` 警告，不把源 Word 标记自动变成已支持资格。本阶段的入口是用户明确创建的结构化表格，不宣称外部 Word 格式无损导入。

## 剩余边界

三页以上、多行表头、跨页合并格、不可区分的重复数据行、拆页图注、横向并排图表仍不支持。真实转换联合验收需要既定 Word03 镜像；B6 的 10 项原生事务测试需要临时 PG17 和核验过的 S3 测试实现。本阶段没有重新拉取不明镜像或修改网络／权限，也没有把这些未运行项目计作通过。
