# 固定来源同章多文字节点原子修订（B6）

## 交付范围与协议

基于独立分支 `b081510`，开发前核实远端同 SHA，PR #2 源分支 `90444507`、目标 `462ec226` 均未移动。此次新增同一章节的 2–20 个现有纯文字段落／标题原子修订，总替换文字最多 20000 字符。单个节点继续使用原 v1 请求；不支持跨章节、富文本标记、增删节点、图片／表格结构或来源变更。

- 后端从不可变父修订重建全部修改，每个节点必须存在且唯一、摘要匹配、类型可编辑、实际有变更。请求不能携带引用、规则或额外资格字段。全批先核验再重建，不修改传入原件。
- 复用原服务的预读取、事务外 S3 原件核验、事务内重新捕获及最终操作者核验；一条命令、一个章节修订、一个草稿快照、一条来源资格和审计，任一失败回滚。相同幂等键恢复原回执，改正文／条件拒绝；来源失效不自动把旧请求改成新请求。
- 新请求 `authoring-exact-multi-text-edit/1`；来源清单 `authoring-exact-manual-revision/2`；方法、能力与结果版本均为 `/2`。v1 的封闭结构不改写，不把 v2 数据伪装成 v1。实际 OpenAPI 与前端生成类型同步。
- 新可选 SQL `packages/contracts/sql/authoring-exact-multi-text-edits.sql` 在 B5 之后安装，保留原单节点校验函数，按不可变 manifest 的协议选择校验器。v2 校验逐节点重建真实父内容，绑定完整请求、根资格、审计、命令回执及唯一后继快照。无新表或新运行账号授权，新增内部函数撤销 PUBLIC/API/Worker 执行权。原 B5 SQL 未修改。
- B6 没安装时仍提供原单节点能力，多节点请求返回未配置。没有用配置开关绕过数据库检查。本次未安装扩展或变更环境权限；既有 B1–B5 fresh-install 清单也没有被静默升级。

## 界面闭环

能力 `/2` 下可切换本章段落并保留各段文字，展示修改节点数量及上限，可展开逐项文字或撤销其中一项；显式核对说明和确认后一次提交。单节点能力下维持原行为。未知 ACK 在会话存储中保留全部原文字、基准、条件和键，刷新后仅显式重试。412 保留整批文字，重新读取并确认新基准后才能提交。组件按成员／标段／稿件／章节隔离，迟到响应不能清除其他选择的恢复记录或显示旧成功。

前端合成多节点回包放在明确标注 synthetic 的测试构造器中；没有改写既有原生单节点 HTTP fixture，也没有将合成回包称为原生验证。
