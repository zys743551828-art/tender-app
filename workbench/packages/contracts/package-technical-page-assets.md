# 静态PDF原页与同像素细节资产

`package-technical-page-assets/2`是当前静态PDF的派生回执，不是公开请求、模型输入、原件权威或历史存在证明。处理器无数据库、对象存储、provider或环境配置端口，尚未连接正式API／Worker。真实不可信原件须先装配独立隔离资产Worker；当前函数只有进程锁和软超时，不作为已安装安全沙箱。

调用渲染必须从owned输入取得文档版本、预期原件摘要／字节数和预期渲染方法摘要；先逐字节校验，再读取原件。方法绑定实现、契约、规范JSON、PNG编解码、PDFium包装／原生版本、运行平台／Python／zlib／验证器及固定参数。匹配调用者给出的摘要本身不授予源权限。

渲染保留全部PDFium物理页可见视口、内嵌旋转和实际画布／MediaBox／显式CropBox；额外裁边为零，注释可见。固定每PDFium画布单位3像素，不把无法证明的PDF用户单位当作物理DPI。表单和孤立Widget在渲染前拒绝，不信外观流、不修复字段或扁平化原件。字体／色彩复现、视觉可读性和页面内容完整性仍未获得独立证明。

回执记录原件摘要、实际派生时间、每页图的像素尺寸、字节摘要及标识，PNG为RGB8／零行过滤／非交错的封闭格式。单原件32MiB、最多128页、单边8192像素、单页2400万像素、总资产1.28亿像素及32MiB；元数据512KiB。先检查所有页和总像素，超限或失败不返回部分结果，不截断或自动降采样。软超时不能抢占阻塞中的原生调用，硬隔离仍须独立运行配置。

细节派生只接收已固定回执及其全部原页字节，预期父回执摘要和当前裁片方法由owned控制器独立提供。请求显式指定物理页、原页图摘要和左上角像素矩形，右／下边界不包含；不接受浮点／布尔坐标或隐式比例。最多128个不重复矩形，不越页、不重采样，不自动判断哪个区域“必要”或“可读”。派生记录保留所有完整原页，按物理页与该页请求顺序列细节；父回执重建摘要和裁片逐像素均可核对，不能替换原页或仅凭新外层摘要接纳伪造裁片。追加其他区域应从原基线生成新的明确候选，不改已有派生记录。

输入／输出闭包见[元数据契约](package_technical_assets.py)。原件权限、完整必要范围、当前效力、解析身份、历史取得／存在时点，以及模型输入上界和真实可读性均须由后续独立权威核验。PDF元数据中的创建日期不作为历史字节已存在依据；`rendered_at`／`cropped_at`仅记录当前派生。输入权威、可读性、历史存在、隔离已验证和字体复现标志始终false。正式三评持久化、受限资产消费、provider和费用／租约闭包仍未装配。
