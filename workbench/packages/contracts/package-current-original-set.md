# 原生完整原件集合读取

`package_current_original_set.collect`接收控制进程明确冻结的项目／scope ID及摘要、控制器方法摘要，以及分别用于scope事实和原件定位的两条独立连接。私有URL签名函数和受限GET客户端由受控进程提供；不发现配置或凭据，不接收调用方提供的文件清单。

先由原生scope入口取得全部冻结原件清单，包括依据包、本方包和来源祖先；在签名及网络读取前检查最多32份、总计64MiB、每份32MiB。按文档ID稳定排序逐份核对原生定位、实际完整GET、长度与SHA-256，不按相同摘要合并不同文档身份，不使用top-k或截断。

每次GET之前两条原生连接都必须idle，数据库事务不跨网络。所有字节完成后重新读取当前scope并逐份核对定位及全部来源；范围失效、来源撤回、定位或方法变化、字节损坏及取消均不返回部分集合。两轮观察只对应各自数据库快照；最后核对后仍可能发生变化，发送前必须另有CAS／lease。

`CurrentOriginalSet`的repr不包含正文。原件字节及完整scope事实只在私有字段提供给后续派生／投影进程；metadata只有确切身份、数量／长度、两轮scope观察摘要、逐份初末定位观察及字节回执。私有对象key、签名URL和正文不进入metadata。签名函数异常丢弃原异常上下文，返回安全码；没有自动重试、付费模型或公开HTTP入口。

`native_scope_and_complete_original_set_observed=true`只说明上述集合读取流程完成。原生解析内容、必要范围、输入权威、执行与历史存在性保持false，不注册正式binding；相同对象在读取后被修改不能由数据库观察证明不存在，字节只证明实际读到的内容。后续还需准确解析重核、受限原页资产、完整材料投影及独立资格登记。

本机合成验证复用已授权的同一可选角色／RPC，仅在现有Compose检查组的全新独立库初始化并清理，不新增数据库权限，不安装到正常业务库。
