# 经配置核验程序的原生命令登记

初始化者配置不可变程序profile和case，分别绑定目标LOGIN及原生角色OID、控制器方法／政策／来源／数据库／有效期，以及准确原生登记、独立审核回执和获准请求LOGIN及其OID；head启用状态与修订另存。目标或请求账号删后同名重建均不继承旧角色OID身份。该配置不证明程序已执行或具有输入授信权限。

专用非owner LOGIN通过material_verification.begin_command在任何新GET或渲染之前持久固定逻辑command；服务器核实际请求者、准确case摘要、当前配置及独立审核状态、当前未提交项目，生成不可变记录ID／时间／session_user。命令状态固定pending_controlled_verification，程序执行／必要范围／原生binding／输入／执行false。

同命令准确重放优先返回旧事实，其他case／主体／内容冲突；read_command按准确case／command／case摘要查回未知结果，读取限本实际请求者。不可变事实与本次程序配置／case的有效状态及head修订分开保存，撤销／过期／替换不改旧命令，新请求失效拒绝。读取不表示当前业务来源或独立审核仍有效，实际程序执行前与完成登记时须另核。

该端口负责持久任务身份，不完成核验、不发放lease或正向输入资格；目标程序之后须以独立运行账号及完整purpose审计消费准确命令，实际执行可信材料核验，再受独立原生登记约束。只在全新独立检查库安装可选SQL，不进BASE／业务库；没有公开HTTP、前端、自动执行、模型或付费调用。
