# 完整材料证据的原生受控存储

用于当前F06完整材料核验的私有证据载体，不提供通用对象存储平台。保存准确context、原取得观察、新实际派生观察、完整审核报告和所有页图／裁片；不复制原件PDF、定位或凭据。受控写入者和独立读取者分开连接，各自仅一种固定RPC，无直接表或其他用途权限。可选新库DDL不进入BASE／正常业务库。

调用方须在上游持久固定command与准确根，端口不临时生成逻辑命令或重取“最新”。写入把规范证据对象与闭合packet作为同一原生事务提交；原生重算每个对象SHA／长度、核准确bid／scope与全部引用覆盖，记录原生UUID／时间／实际主体。内容完全一致的同command重放原记录，冲突拒绝；结果未知可按原bid／command／packet摘要独立查回。对象和记录不出现部分提交。

packet闭合为版本、存储方法、context／context方法／原取得观察／新派生观察／范围清单／报告根，以及四个具名对象和有序image_objects。每个对象固定SHA与字节数，图片另固定准确asset_id。相同PNG可复用相同对象SHA，资产身份不能混用。原生读取须固定所属记录，只允许读取该记录引用的对象；不提供列举、任意SHA读取或定位查询。

数据对象仍须由读取者重新完整复验，存储摘要和实际writer只证明这份原始bytes被该主体登记。派生声明、实际渲染、人工阅读、必要范围、原生binding、正向输入、执行与历史存在不由存储自证；服务器资格位全部false。正向资格登记须另核经配置的可信程序／审核主体和当前来源，发送还须独立lease／fence。

context上限12MiB、原取得观察2MiB、新派生观察4MiB、完整报告8MiB加4096、PNG合计64MiB且至多384资产；总预算为这些上限之和，拒绝超量、不截断。方法绑定Python／SQL源码和纯复验方法，平台特定实际渲染方法作为被固定声明保留，不以服务器运行平台替换其身份。
