# 整包三次判断的非数值特征投影

`package-technical-feature-projection/2`是已拥有任务的控制器提供给纯CPU特征处理器的内部投影，不是模型输入、公开请求或完整输入资格证明。正式来源、完整范围、原件／页图可读性、供应商回执与费用必须由独立输入和执行权威核验。当前没有连接正式API、Worker或数据库RPC，不沿用隔离机制测试的执行权限。

调用必须分别提供由owned任务固定的`expected_projection_digest`和`expected_method_digest`。不能从收到的任意投影自行计算预期值并授予资格。处理器核对完整投影的规范JSON摘要、当前特征方法身份、封闭字段和上界；多余官方标签、资格开关、旧/1结构、浮点数或摘要不符均拒绝。不截断输入。

输入／输出JSON Schema见[封闭契约](package_technical_features.py)。方法描述绑定处理器、契约、规范JSON算法源文件、输入／输出Schema与jsonschema实际版本；模型别名不作为不可变权重身份。投影上界16MiB，1—400条要求，每条三个槽位、每槽最多五次且以固定策略为准；证据与坐标、原文、档位、维度均有闭包和长度上界。

每个规则声明固定语义输入、请求摘要、必要范围和档位列表。回执逐项绑定规则、槽位、尝试序号、调用ID、供应商响应ID、模型响应名称、原响应摘要及判断摘要，同一供应商响应和调用不能复用。每槽的尝试序号连续；已有有效成功或未对账unknown后不能追加尝试。失败／无效回执不充作有效槽位，未完成部分保留缺口与已完成规则，不补零、不插值。这里不发送、重试、结算、对账或证明真实供应商调用。

声明有效的判断必须覆盖完整声明范围，档位属于冻结列表（没有档位权威时只能为空）；每个必要子范围须有投影中原证据引用。文档、解析、物理页、页图摘要必须一致，同一冻结物理页的各证据块共用相同页图摘要和尺寸；原文逐字包含于投影原文且原文摘要正确，图像区域是同页像素中的非空矩形，不能逃出页边界。此核对不证明原件字节、图页真实性、内容完整或视觉可读性，输出对应授权标志始终false。

`package-technical-features/2`只为具有三个有效槽位的规则给档位票数、保留并列的众数档位、分歧标记及具体性／有效性／一致性的supported／unsupported／uncertain计数。没有档位映射仍可保存维度特征。图表数量不是加分特征，三次多数不是独立真值或置信区间。`feature_coverage`仅指该固定投影中的规则，不是整包完整覆盖。

输出保留原绑定、投影／方法摘要、尝试数量、有效／缺失／未知槽位、有效调用／响应与证据ID。`raw_numeric_total`、`formal_prediction`始终null；输入权威、原字节复验、视觉可读、正式预测、训练、指标资格均不由本处理器授予。完整原始判断／无效响应和实际费用继续由原账本保留，不能拿特征行替代它们。正式图文输入、受限资产消费、独立三次调用、原生持久化与后续数值／校准／受控发布仍需各自实现和验证。
