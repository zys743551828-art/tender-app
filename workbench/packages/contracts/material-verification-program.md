# 核验目标程序认证消费与完成回执

独立目标程序LOGIN使用material_verification.program_context取得准确已登记命令、控制器／政策和服务器联结的登记／审核引用。实际LOGIN与角色OID必须匹配不可变程序配置，专用purpose只有取任务与保存完成回执两种RPC，无表、其他schema或业务API／Worker权限。请求者不能冒程序，程序不能改case或自行配置身份。

命令已完成时只读回原生不可变事实，不重取原件或重放渲染；返回不构造LiveVerifiedMaterial。待执行命令须当前程序／case、请求者和审核状态有效，程序或case head修订变化拒绝旧任务。程序入口从原生命令构造固定引用，实际调用可信材料核验过程，不接受HTTP正文、自报资格或外部运行回执；原件定位来自受控启动配置和原生端口。

完成观察固定命令、程序／端口方法、政策、字节读取profile及完整实时核验观察。服务器核实际目标身份、原生配置、准确登记／审核／context／完整报告和前后修订，再追加完成UUID、时间与程序LOGIN／OID。每命令一份完成事实，准确重放或未知结果查回保持原记录，其他观察冲突。源或授权变化不改旧事实，新执行必须重新核验。

回执只证明经配置目标程序已认证记录该核验结果；人工内容真值、必要范围、输入／执行、历史存在、原子快照和发送lease均不因此授予。合成origin只用于软件机制，不升级生产输入。独立正向输入资格与封存须另走受审原生政策和当前来源核验。

仅全新独立检查库安装可选SQL和独立账号，旧命令／方法／BASE／业务库不改。实际运行限定可信宿主固定Compose隔离，不给API／Worker Docker socket；无自动后台接续、供应商或付费调用。
