# 冻结输入合成界面夹具

在 `apps/web` 目录，复用现有 Node 22 运行 `node qa-previews/frozen-inputs/build.mjs`，前提是已有普通 Vite 构建。固定 Compose 的 web 挂载该 dist，可通过 `http://127.0.0.1:5188/_qa/index.html` 打开。下一次普通 Vite 构建会移除 `_qa`；交付预览前必须移除夹具构建。

夹具使用真实保存组件及构建后的工作台样式，只在此页面内模拟 fetch，不连接业务库。默认模拟断网：显式保存后出现未决恢复；取消模拟断网再恢复，校验固定合成回执并显示记录。历史目录首屏有两条合成记录，“加载更多”追加第三条；点选后返回对应ID、摘要、创建人、输入／上下文及冻结时点匹配的完整合成记录。历史读取同样使用合成响应。不要将其计为真实上传、原件核验或 API 业务验收。

点选完整历史记录后，可显式点击“复核此冻结输入的当前条件”。夹具返回同一合成记录的只读观察：解析匹配、原件字节未重核、事实资格未证明、执行与发布均不可用。这不代表真实执行或原件核验通过。

可选容器宽度 1200、768、390px，验证长摘要、记录编号、错误和历史展开的换行。容器检查不等同于手机视口或完整工作台断点验收。离开前点击“重置夹具记录”，仅清除本夹具的固定成员／项目／包／清单恢复记录。
