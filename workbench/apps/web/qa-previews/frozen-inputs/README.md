# 冻结输入合成界面夹具

在 `apps/web` 目录，复用现有 Node 22 运行 `node qa-previews/frozen-inputs/build.mjs`，前提是已有普通 Vite 构建。固定 Compose 的 web 挂载该 dist，可通过 `http://127.0.0.1:5188/_qa/index.html` 打开。下一次普通 Vite 构建会移除 `_qa`；交付预览前必须移除夹具构建。

夹具使用真实保存组件及构建后的工作台样式，只在此页面内模拟 fetch，不连接业务库。默认模拟断网：显式保存后出现未决恢复；取消模拟断网再恢复，校验固定合成回执并显示记录。历史目录首屏有两条合成记录，“加载更多”追加第三条；点选后返回对应ID、摘要、创建人、输入／上下文及冻结时点匹配的完整合成记录。历史读取同样使用合成响应。不要将其计为真实上传、原件核验或 API 业务验收。

点选完整历史记录后，可显式点击“复核此冻结输入的当前条件”。夹具返回同一合成记录的只读观察：解析匹配、原件字节未重核、事实资格未证明、执行与发布均不可用。这不代表真实执行或原件核验通过。

可选容器宽度 1200、768、390px，验证长摘要、记录编号、错误和历史展开的换行。容器检查不等同于手机视口或完整工作台断点验收。离开前点击“重置夹具记录”，仅清除本夹具的固定成员／项目／包／清单恢复记录。

准备输入下可显式核对事实，在“事实适用范围”中读取原事实列表，按名称和值摘要选定事实并核对当前范围，明确主体和理由后保存；编号入口用于准确历史定位。摘要来自指定prepared，名称／值／原主体／原范围和单位各最多240码点，截断明确提示。范围声明与历史、当前匹配分别展示；“下一次范围保存丢失回执”在模拟记录已经留存之后抛错，恢复时返回同键原记录。来源停用开关使新绑定不可用，仍可撤回旧声明；原历史记录保持不变。此链仅为真实组件的合成HTTP验证，不连接业务库、不证明材料质量或正式事实资格。

## 整包范围核查、人工意见、两轮对比与报告副本

已有普通 Vite 构建后，在 `apps/web` 执行：

```sh
node qa-previews/frozen-inputs/build-package-review.mjs
```

合成入口为 `/_qa/package-review.html`。使用真实 `PackageReviewProgress`、`PackageReviewComparisonWorkspace` 和 `PackageReviewReportExports`，可选择结果／人工意见、两轮对比、报告恢复三类界面，以及 1200、768、390 像素内容容器。页面明确列出两轮合成运行编号；手动选择后读取对比。报告可模拟一次丢回执，再从原请求恢复。

本夹具的机器结果、人工记录、固定报告依据和模拟响应均在页面内运行。生成依据使用固定合成快照，不能将其用于验收服务端人工版本冲突或报告真实排版；对应语义由真实 API 集成测试和受控组件测试分别覆盖。下载字节刻意不是有效 DOCX／PDF，本页不提供有效生成文件、真实私有原件或模型质量测量。不会向业务服务发送请求。

可通过本地 Playwright 运行实际视口验收。先完成普通 Vite 构建及上述夹具构建，再执行：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
BROWSER_EXECUTABLE=/absolute/path/to/chrome-headless-shell \
PACKAGE_REVIEW_QA_OUTPUT=/absolute/path/to/qa-output \
node qa-previews/frozen-inputs/check-package-review.mjs
```

如果项目环境本身能解析 `playwright` 包且浏览器已安装，可以省略前两个变量；默认输出到 `.local/package-review-visual`。脚本只在本机回环随机端口提供已有 `dist`，在三个独立浏览器上下文中分别检查 1200、768、390 像素真实视口。它拒绝外部网络，实际操作人工意见保存、对比单条原结果定位、报告丢回执后按原键与原体恢复，并断言无横向溢出、控件越界及未处理异常。每个视口生成页面与人工引用截图，最后输出 `receipt.json`；截图仍须逐张人工检查。

2026-10-20 已使用 Chrome for Testing 156.0.8078.47 与 Playwright 1.62.1 完成九组检查，并根据实际截图修复人工引用选择的全局样式继承问题。结果见 `docs/completion-20261021/frontend-scope-review-acceptance.md`。这是实际浏览器中的合成 UI 验收，不能计为业务 API、模型效果或真实报告文件通过。普通 Vite 构建会删除 `_qa`，不要把该目录包含在生产交付中。
